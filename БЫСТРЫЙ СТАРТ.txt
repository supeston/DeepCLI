====================================================================
DEEPX CLI — БЫСТРЫЙ СТАРТ
====================================================================

1. ЗАПУСК НА WINDOWS
   › Откройте файл:  start.bat   (или run_cli.vbs для Windows Terminal)

   При первом запуске программа автоматически:
   · найдёт Python 3.10+ (или скачает и установит Python 3.11),
   · создаст локальное окружение .venv и поставит зависимости,
   · установит движок Chromium для Playwright,
   · откроет окно входа в chat.deepseek.com (один раз).

2. АВТООБНОВЛЕНИЕ
   · При старте CLI проверяет свежую версию на GitHub.
   · Если вышла новая версия, в баннере появится строка:
     ▸ update to X.Y.Z · run /update to install
   · Для установки введите /update внутри CLI (или start.bat --update).
   · Ваши .env, state.json, .venv и .deepx сохраняются автоматически.

3. ОСНОВНЫЕ КОМАНДЫ ВНУТРИ CLI
   /help       — список всех команд
   /mode       — переключить режим (instant, think, plan)
   /style      — выбрать профиль (coder, universal, osinter)
   /cd <путь>  — сменить рабочую директорию проекта
   /undo       — откатить изменения файлов за последний ход
   /compact    — сжать историю инструментов
   /status     — показать активные параметры и статус обновлений
   /update     — проверить и установить обновление
   Ctrl+X      — остановить текущую генерацию
   Ctrl+C      — подтверждение выхода из программы
