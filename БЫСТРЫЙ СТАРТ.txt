====================================================================
DEEPX CLI — БЫСТРЫЙ СТАРТ
====================================================================

1. УСТАНОВКА В СИСТЕМУ ОДНОЙ КОМАНДОЙ (PowerShell)
   irm https://raw.githubusercontent.com/supeston/DeepCLI/main/install.ps1 | iex

   После установки команда  deepx  работает из любой папки в терминале.
   Если запущена классическая консоль и установлен Windows Terminal,
   deepx автоматически откроется в новом Windows Terminal и закроет старое окно.

2. ЗАПУСК ЛАУНЧЕРА НА WINDOWS
   › Откройте файл:  run_cli.vbs

   VBS-лаунчер автоматически:
   · найдёт Python 3.10+ (или установит Python 3.11),
   · откроет Control Hub в Windows Terminal (или классической консоли
     на системах до Windows 11 без установленного Windows Terminal),
   · позволит стрелками (↑/↓) запустить агента, проверить обновления,
     проверить/восстановить зависимости и закрепить команду deepx.

3. АВТООБНОВЛЕНИЕ
   · При старте CLI проверяет свежую версию на GitHub.
   · Если вышла новая версия, в баннере появится строка:
     ▸ update to X.Y.Z · run /update to install
   · Для установки введите /update внутри CLI (или deepx --update).
   · Ваши .env, state.json, .venv и .deepx сохраняются автоматически.

4. ОСНОВНЫЕ КОМАНДЫ ВНУТРИ CLI
   /help       — список всех команд
   /mode       — переключить режим (instant, think, plan)
   /style      — выбрать профиль (coder, universal, osinter)
   /cd <путь>  — сменить рабочую директорию проекта
   /undo       — откатить изменения файлов за последний ход
   /compact    — сжать историю инструментов
   /status     — показать активные параметры и статус обновлений
   /update     — проверить и установить обновление
   Ctrl+X      — остановить текущую генерацию
   Ctrl+C      — подтверждение выхода из программы
