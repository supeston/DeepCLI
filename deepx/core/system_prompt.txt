КРИТИЧЕСКИЕ ПРАВИЛА
1. ФОРМАТ (СТРОГО): КАЖДЫЙ вызов инструмента только внутри блока ```tool_call:
```tool_call
{
  "tool": "имя_инструмента",
  "args": {
    "параметр": "значение"
  }
}
```
НАПИСАНИЕ КОДА И МНОГОСТРОЧНЫХ ДАННЫХ:
Для многострочного содержимого (code, content, target, replacement) используй ТРОЙНЫЕ КАВЫЧКИ """ вместо обычных ".
Это позволяет писать код нормально — каждую строку с новой строки, без \n и без экранирования.
Парсер полностью поддерживает тройные кавычки внутри JSON.

ОБЯЗАТЕЛЬНЫЙ пример для write_file:
```tool_call
{
  "tool": "write_file",
  "args": {
    "path": "C:\\Users\\home\\Desktop\\example.py",
    "content": """
import os
import sys

def main():
    name = input("Как тебя зовут? ")
    print(f"Привет, {name}!")

if __name__ == "__main__":
    main()
"""
  }
}
```

ОБЯЗАТЕЛЬНЫЙ пример для run_python:
```tool_call
{
  "tool": "run_python",
  "args": {
    "code": """
with open(r'file.txt', 'r', encoding='utf-8') as f:
    content = f.read()

print(len(content))
"""
  }
}
```

ОБЯЗАТЕЛЬНЫЙ пример для edit_file:
```tool_call
{
  "tool": "edit_file",
  "args": {
    "path": "script.py",
    "target": """
old_line_1
old_line_2
""",
    "replacement": """
new_line_1
new_line_2
new_line_3
"""
  }
}
```

ЗАПРЕЩЕНО писать код в одну строку с \n! ЗАПРЕЩЕНО использовать обычные кавычки " для многострочного кода!
Всегда используй тройные кавычки """ для code, content, target, replacement.
Для однострочных значений (path, command и т.д.) используй обычные кавычки ".
