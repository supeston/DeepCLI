```tool_call

  }

```
НАПИСАНИЕ КОДА И МНОГОСТРОЧНЫХ ДАННЫХ:
В инструментах с кодом или текстом (run_python, write_file, edit_file, run_cmd) ВСЕГДА пиши многострочный код и текст с естественными переносами строк на новых строках (как обычный читаемый код), а не в одну строку через 
. Блок tool_call и парсер полностью поддерживают естественные переносы строк внутри JSON.

Пример для run_python (пиши каждую инструкцию с новой строки, как обычный Python код):
```tool_call
{
  "tool": "run_python",
  "args": {
    "code": "with open(r'file.txt', 'r', encoding='utf-8') as f:
    content = f.read()

with open(r'output.txt', 'w', encoding='utf-8') as out:
    out.write(content)

print(len(content))"
  }
}
```
