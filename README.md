## ✨ Что такое DEEPX?

**DEEPX (DeepCLI)** — это автономная терминальная среда разработки и исследований, которая превращает веб-интерфейс DeepSeek в полноценного агентного ассистента программиста, аналитика и OSINT-исследователя **без необходимости оплачивать API-токены**.

Агент выполняет задачи по циклу ReAct (Reasoning + Action), самостоятельно планирует действия, вызывает инструменты, запускает код и команды в системе, проверяет результат и адаптирует стратегию при ошибках.

## 🔥 Что нового (Эволюция проекта)

По сравнению с начальной версией произошёл глобальный архитектурный и функциональный скачок:

### 1. Модульная архитектура пакета (`deepx/`)
- Полный рефакторинг из монолитных скриптов в чистую, масштабируемую структуру:
  - `deepx.core` — конфигурации, системные промпты, константы и параметры окружения.
  - `deepx.api` — оптимизированный клиент автоматизации DeepSeek с поддержкой `playwright-stealth 2.x`, авто-переподключением и стримингом рассуждений (DeepThink).
  - `deepx.agent` — ReAct-раннер, строгий протокол верификации шагов, управление контекстом и автодополнение команд.
  - `deepx.tools` — модульные миксины инструментов (System, Filesystem, Browser, Documents, OSINT, Todo, Project Memory).
  - `deepx.parser` — отказоустойчивый парсер вызовов инструментов с поддержкой XML-тегов, многострочных кавычек `"""` и авто-исправлением путей Windows.
  - `deepx.ui` — адаптивный терминальный интерфейс Rich/Prompt-Toolkit, баннеры, цветовые схемы и перехват горячих клавиш.

### 2. Фоновые процессы (Background Tasks Engine)
- Агент умеет запускать долгие процессы и сервера в фоне (`run_background_cmd`), проверять их статус (`task_status`) и читать логи (`task_log`) без зависания основного CLI.

### 3. Интерактивный Live ToDo-трекер (`todo`)
- Живой список задач прямо на экране с цветовой индикацией статусов: `○ pending`, `● active`, `✔ done`, `✖ cancelled`. Агент динамически обновляет пункты по мере выполнения.

### 4. Долгосрочная память проектов (`project_memory`)
- Постоянный контекст в `.deepx_project_memory.json` для сохранения целей, архитектурных решений, фактов и истории этапов между сессиями.

### 5. Генерация документов и архивов (Office Suite)
- Встроенные инструменты для создания полноценных документов без сторонних скриптов:
  - 📊 `make_excel` — генерация `.xlsx` таблиц с множеством листов.
  - 📝 `make_docx` — создание форматированных Word-документов с заголовками и параграфами.
  - 📽 `make_pptx` — генерация слайдов PowerPoint.
  - 📦 `zip_pack` / `unzip_pack` — архивация и распаковка файлов.

### 6. Встроенный автономный поиск и скрапер
- `web_search` — мгновенный поиск через DuckDuckGo без API-ключей, с поддержкой операторов dorking (`site:`, `filetype:`, `"фраза"`).
- `fetch_url` — быстрое извлечение чистого читаемого текста с веб-страниц без накладных расходов браузера.

### 7. Полнофункциональный браузерный агент Playwright
- `browser_action` — клики по стабильным ref-меткам (`e1`, `e2`), заполнение форм, управление вкладками, снимки экрана, ожидание элементов, перехват загрузок и оценка JS в контексте страницы с включенным stealth-режимом.

### 8. Специализированные профили (Стили агента)
- Мгновенное переключение поведения и набора инструментов одной командой (`/style`): **CODER**, **UNIVERSAL**, **OSINTER**.

### 9. Параллельное выполнение безопасных инструментов
- Contiguous read-only инструменты (`read_file`, `web_search`, `fetch_url`, `dadata_osint`, `list_dir`) исполняются параллельно, значительно ускоряя исследовательские задачи.

### 10. Прямой VDS/VPS Деплой-движок (`vds_deploy`)
- Полнофункциональный инструмент автономного удалённого администрирования и развёртывания:
  - ⚡ **Мгновенный SSH/SFTP пул соединений** — постоянные сессии без задержек и без зависаний стандартного OpenSSH Windows на запросах паролей.
  - 🚀 **Команды и скрипты** — выполнение удалённых bash-команд (`exec`) и многострочных скриптов (`script`) с флагом `-e` и `sudo`.
  - 📁 **Скоростной SFTP-деплой** — синхронизация файлов и директорий (`upload`/`download`) с умным исключением мусора (`.git`, `__pycache__`, `.venv`, `node_modules`).
  - ⚙️ **Управление сервисами и Docker** — готовые действия для Systemd (`service`: `start`, `restart`, `logs`, `status`) и Docker Compose (`docker`: `up`, `logs`, `ps`).
  - 🎯 **One-Click Quick Deploy** — комплексный пайплайн (`quick_deploy`): загрузка проекта -> запуск команд сборки -> конфигурация/перезапуск сервиса -> healthcheck.
  - 🔐 **Профили серверов** — сохранение реквизитов серверов (`save_profile`, `list_profiles`) в `.deepx/vds_profiles.json` и поддержка `.env` (`VDS_HOST`, `VDS_USER`, `VDS_PASSWORD`, `VDS_KEY_PATH`).

## 🎭 Стили агента (Роли)

Вы можете переключать специализацию агента в любой момент:

| Стиль | Описание | Доступные ключевые инструменты |
|---|---|---|
| 💻 **`CODER`** *(по умолчанию)* | Системный разработчик и инженер. Проектирование, чистый код, рефакторинг, отладка, тесты, запуск команд, VDS/SSH деплой и браузерная отладка. | `run_cmd`, `run_python`, `run_background_cmd`, `vds_deploy`, `read_file`, `write_file`, `edit_file`, `web_search`, `browser_action`, `todo`, `project_memory` |
| 🌐 **`UNIVERSAL`** | Аналитик, копирайтер и продуктовый ассистент. Исследования, тексты, аналитические сводки, деплой и создание готовых офисных файлов. | Все базовые инструменты + `vds_deploy`, `make_excel`, `make_docx`, `make_pptx`, `zip_pack`, `unzip_pack` |
| 🕵️‍♂️ **`OSINTER`** | Специалист по Deep Research и цифровой разведке. Проверка контрагентов, анализ Telegram-аккаунтов, поиск по реестрам, анализ инфраструктуры. | `funstat_osint`, `dadata_osint`, `web_search`, `fetch_url`, `browser_action`, `run_python`, `make_docx`, `make_excel` *(включена защита ядра)* |

## ⚡ Быстрый старт и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/supeston/DeepCLI.git
cd DeepCLI
```

### 2. Создание и активация виртуального окружения
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
playwright install chromium
```

### 4. Настройка `.env`
Скопируйте шаблон конфигурации:
```bash
# Windows (cmd/PowerShell)
copy .env.example .env

# Linux / macOS
cp .env.example .env
```
*(Ключи для OSINT указывать не обязательно — если они не заданы, агент продолжит работу со всеми остальными инструментами).*

### 5. Запуск
```bash
# Рекомендуемый запуск в 1 клик на Windows:
# Просто запустите run_cli.vbs

# Либо через терминал:
python -m deepx
```

> 💡 **Первый запуск:** При первом старте откроется окно браузера Chromium для авторизации в **chat.deepseek.com**. Войдите в свой аккаунт — сессия автоматически сохранится в локальный файл `state.json`, и все последующие запуски будут проходить мгновенно в тихом фоновом режиме.

> 🪟 **Пользователям Windows:** Для максимального удобства запускайте скрипт через `run_cli.vbs` — он автоматически откроет новую вкладку в **Windows Terminal** с оптимальным разрешением.

## ⌨️ Слэш-команды в терминале

Во время работы в строке ввода доступны быстрые интерактивные команды (с автодополнением по клавише `Tab`):

- `/mode` — смена режима модели (`Instant`, `Expert`, `Vision`) с созданием чистого диалога.
- `/style` — переключение роли агента (`Coder`, `Universal`, `OSINTer`).
- `/think` — включение / выключение движка глубоких рассуждений **DeepThink**.
- `/search` — переключение встроенного веб-поиска DeepSeek *(для режима Instant)*.
- `/menu` — открытие графического TUI-меню настроек.
- `/new` — начать новую сессию / диалог с чистого листа.
- `/status` — показать текущие параметры сессии и пути.
- `/stealth` — диагностика маскировки браузера (версия `playwright-stealth`).
- `/copy` — скопировать последний ответ агента в буфер обмена.
- `/clear` — очистить экран терминала с сохранением баннера.
- `/help` — показать список всех доступных команд.
- `/exit` — выход из программы.

## ⚙️ Настройка окружения (.env)

В файле `.env` можно указать дополнительные ключи интеграций:

```env
# Funstat / Telelog OSINT (https://telelog.org или @funstat_bot)
FUNSTAT_API_TOKEN=your_token_here

# DaData OSINT (https://dadata.ru)
DADATA_API_KEY=your_api_key_here
DADATA_SECRET_KEY=your_secret_key_here
DADATA_ALLOW_PAID=false
```

## 🔒 Безопасность и самозащита

- **Защита исходного кода:** Внутренняя система безопасности предотвращает случайное удаление, повреждение или перезапись файлов самого агента, конфигураций `.env` и сохранённых сессий `state.json`.
- **Проверка синтаксиса:** Любой Python-код перед записью валидируется через `py_compile`.
- **Редактирование через Diff:** Инструмент `edit_file` точечно заменяет фрагменты кода с проверкой контекста.
- **Маскировка токенов:** Все системные логи и выводы ошибок автоматически маскируют чувствительные токены и API-ключи.
